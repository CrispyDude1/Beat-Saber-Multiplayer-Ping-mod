# Ping Mod

The Ping Mod lets you see each player's ping while in a Beat Saber multiplayer lobby. It displays a small label above each player's avatar showing their connection in milliseconds (ms).

## Features

- **Live Ping Display:** Shows each player's ping while waiting in a multiplayer lobby.
- **Player Labels:** Displays ping directly above each player's avatar.
- **Real Connection Data:** Uses the actual ping information available from the game.
- **Easy to Read:** Lets you quickly check everyone's connection while hanging out in the lobby.

## How It Works

When you join a Beat Saber multiplayer lobby, the mod detects the players and displays a ping label above each player's avatar.

Ping is measured in milliseconds (ms). Lower ping generally means a more responsive connection, while higher ping can mean a less stable or slower connection.

The displayed values update during the lobby so you can see how everyone's connection is doing.

## Important

**The Ping Mod only works in multiplayer lobbies.** Ping labels are not displayed while an actual song is playing. This is intentional, since the main purpose is to let players check everyone's connection while waiting in the lobby, rather than distracting them during gameplay.

## Installation

1. Make sure you have a compatible Beat Saber mod loader installed.
2. Place `PingMod.dll` into your Beat Saber `Plugins` folder.
3. Launch Beat Saber.
4. Join a multiplayer lobby to see the ping labels above players' avatars.

Enjoy!
